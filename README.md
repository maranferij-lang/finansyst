# Фінансист у кишені

Прототип MVP команди 3, StartUp Camp від Raiffeisen Bank.

Помічник для ФОПа-продавця: кожне надходження автоматично розкладається по конвертах (податки, закупівля, операційні, маркетинг, резерв, «собі»), а платіжний радар попереджає про касовий розрив і закриває його овердрафтом банку-партнера в один клік.

## Дві версії
- Мобільний застосунок (PWA): https://maranferij-lang.github.io/finansyst/
- Вебверсія для комп’ютера: https://maranferij-lang.github.io/finansyst/web/

Дані між версіями спільні в межах одного браузера.

## Що працює
- Встановлюється на телефон як застосунок (PWA): Safari або Chrome, «Поділитися» → «На екран Додому».
- Налаштування відсотків: група ФОП підтягує податок, решту часток задає власник.
- Вхідний платіж: справжня тестова оплата через WayForPay (тестовий мерчант `test_merch_n1`) або імітація. Гроші спершу з'являються на рахунку загальною сумою, кнопка «Поділити по конвертах» розкладає їх за відсотками.
- Платіжний радар: прогноз конверта «Витрати» на 30 днів, push про касовий розрив, кнопка «Перекрити розрив (взяти овердрафт)». Без овердрафту можна перекинути гроші з «Резерву» і «Собі» або перенести платіж.
- Овердрафт: автопогашення 30% з кожного надходження (після відкладення податку, до поділу решти по конвертах; можна вимкнути) і кнопка «Погасити зараз».
- Авто-показ для пітчу: перемикач «Вручну / Авто» в панелі сценарію сам проходить 10 кроків демо з підписами (чернетка тексту).
- «Можна витратити на себе» і «Вивести собі» з перевіркою за радаром, календар платежів з оплатою прямо із застосунку (імітація), блок «Пробний період».
- Демо особистого кабінету: вхід за телефоном і кодом, профіль ФОПа.
- «Перший запуск» (кнопка в панелі демо): вхід, згода банку на доступ до виписки, дані з банку, «ось що ми знайшли у виписці» з відповідями так/ні, стартові відсотки, каси й еквайринг, сповіщення. «Нова виписка з банку» показує, як застосунок сам оновлює дані: знайомий платіж враховує сам, у незнайомому питає так/ні. Усе це імітація.

## Що хардкод для MVP
- Дашборд: продажі за тиждень, посилки Нової пошти в дорозі, чеки з каси Checkbox, історія надходжень.
- Овердрафт: API Raiffeisen для рахунків ФОП не підтверджено, тому рішення банку імітується, умови (24% річних, погашення 30% з надходжень) умовні.

## Тестова оплата
Картка `4111 1111 1111 1111`, термін будь-який у майбутньому, CVV будь-який. Справжні гроші не списуються.

Тестовий секретний ключ WayForPay публічний і лежить у коді тільки для демо. У бойовій версії підпис `merchantSignature` рахується на сервері.

## Стек
Один `index.html` без збірки, `manifest.webmanifest`, `sw.js`. Хостинг: GitHub Pages.

## Для команди
- `CLAUDE.md`: увесь контекст проєкту, рішення команди, модель даних, відкриті питання. Відкрий репо у своєму Claude, і він прочитає цей файл сам.
- `tests/`: автотести на Playwright, як запускати, описано в `CLAUDE.md`.
